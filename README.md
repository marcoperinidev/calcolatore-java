# Calcolatore Java

Semplice calcolatrice desktop realizzata in **Java 17** e **JavaFX** come esercizio di programmazione per l'I.T.I. Volta.

## Download

Sono disponibili build native per:

- Windows (`.exe`)
- Linux (`.deb`)
- macOS (`.dmg`)

### [Download ultima release](../../releases/latest)

Build generate automaticamente tramite **GitHub Actions**.
